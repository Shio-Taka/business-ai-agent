# Business AI Agent

自然言語による指示から会議室の空き状況を確認し、ユーザーの確認後に会議室を予約するAIエージェントです。

Gemini APIのTool Callingを利用し、AIが必要な情報を判断してツールを呼び出すエージェントループをTypeScriptで実装しています。

## 概要

ユーザーが自然言語で会議室の予約内容を入力すると、AIが予約に必要な情報を抽出・判断します。

例えば、

> 明日の14時から15時まで、5人で会議室を予約したい

と入力すると、AIが「明日」を具体的な日付に変換し、会議室の空き状況を検索します。

空いている会議室が見つかった場合は、ユーザーに予約内容を確認してから予約を実行します。

## 主な機能

- **自然言語による会議室予約**
- **「明日」「明後日」などの相対日付への対応**
- **予約情報が不足している場合の追加質問**
- **会議室の空き状況検索**
- **ユーザー確認後の会議室予約**
- **利用可能な会議室がない場合の処理**
- **参加人数などの不正入力のバリデーション**
- **Tool Callingによるツール実行**
- **Vitestによるユニットテスト**

## Tool Calling

AIエージェントから以下のツールを呼び出します。

### get_available_rooms

指定された日時と参加人数から、利用可能な会議室を検索します。

入力例:

    {
      "date": "2026-08-18",
      "startTime": "14:00",
      "endTime": "15:00",
      "participants": 5
    }

結果例:

    [
      {
        "id": "room-b",
        "name": "会議室B",
        "capacity": 8
      },
      {
        "id": "room-c",
        "name": "会議室C",
        "capacity": 12
      }
    ]

### book_room

ユーザーの確認後、指定された会議室を予約します。

予約を実行する前に、

    この予約を実行しますか？（はい / いいえ）

とユーザーへ確認します。

「はい」の場合のみ予約を実行します。

## 自然言語処理

以下のような自然な入力に対応しています。

    明日の14時から15時まで、5人で会議室を予約したい

AIが以下の予約情報を判断します。

- **日付**
- **開始時刻**
- **終了時刻**
- **参加人数**

「明日」「明後日」などの相対日付は、現在日時を基準に具体的な日付へ変換します。

また、

    明日の会議室を予約したい

のように情報が不足している場合は、AIが不足している情報を質問します。

## 入力バリデーション

不正な入力についても処理しています。

例えば参加人数が0人の場合、

    14時から15時まで、0人で会議室を予約したい

と入力すると、会議室検索を実行せず、参加人数を1人以上に修正するよう案内します。

また、13人など会議室の定員を超える人数の場合は、利用可能な会議室がないことを通知します。

## テスト

Vitestを使用して会議室検索ツールのユニットテストを実装しています。

テスト内容:

- **5人の場合、利用可能な会議室を取得できる**
- **13人の場合、利用可能な会議室がない**
- **参加人数が0人の場合、エラーになる**
- **終了時刻が開始時刻より前の場合、エラーになる**

テストの実行:

    npm test

現在、4テストすべてが成功します。

## セットアップ

### 1. リポジトリを取得

    git clone <repository-url>
    cd business-ai-agent

### 2. パッケージをインストール

    npm install

### 3. 環境変数を設定

プロジェクト直下に `.env` ファイルを作成します。

    GEMINI_API_KEY=your_api_key

### 4. 開発環境で実行

    npm run dev

### 5. ビルド

    npm run build

### 6. ビルド後に実行

    npm start

## 実行例

入力:

    明日の14時から15時まで、5人で会議室を予約したい

AIが空室を検索します。

    Tool: get_available_rooms

    Tool result:
    [
      { id: 'room-b', name: '会議室B', capacity: 8 },
      { id: 'room-c', name: '会議室C', capacity: 12 }
    ]

その後、ユーザーに確認します。

    会議室B（定員8名）を
    2026-08-18 14:00〜15:00で予約します。

    この予約を実行しますか？（はい / いいえ）:

「はい」と入力すると、

    Tool: book_room

    AI: 予約が完了しました。
    会議室: 会議室B
    日時: 2026-08-18 14:00〜15:00
    利用人数: 5名

となります。

## プロジェクトの目的

単純なチャットボットではなく、LLMがユーザーの自然言語による依頼を解釈し、必要に応じてツールを選択・実行するAIエージェントの仕組みを実装することを目的としています。

特に、

- **自然言語からの情報抽出**
- **Tool Calling**
- **ユーザー確認を挟んだ処理**
- **入力不足・不正入力への対応**
- **ツール実行結果に基づく処理**

を実装しています。
